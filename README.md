## 📋 Project Description
Automated ticket classification system in ServiceNow using Flow Designer.

When a new incident is created (like INC0010005), the system automatically:
- Classifies the ticket based on short description
- Assigns category & priority
- Routes to correct assignment group

## ⚙️ How It Works
1. User creates Incident - INC0010005
2. Flow Designer triggers automatically
3. AI/Service Agent classifies the ticket
4. Ticket assigned with correct category

## 🛠️ Technologies Used
- ServiceNow
- Flow Designer
- Agentforce Builder
- Incident Management
